{% comment %} Search and filtering swap only the results region over HTMX. A full-page reload was costing the filter rail's open groups and the scroll position on every refinement — and a refinement is something people do five or six times in a row. `hx-push-url` keeps the address bar honest, so a filtered search is still something you can bookmark or send to someone. "/" focuses the search box — the shortcut every search-first product shares. It is ignored while typing so it cannot swallow a slash mid-word. {% endcomment %}
{% comment %} The "/" shortcut is its own component, nested rather than merged: the filter dialog and a keyboard shortcut are unrelated concerns, and the CSP build needs each expression to belong to the data object it names. {% endcomment %}
