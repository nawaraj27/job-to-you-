{% comment %} History, made comparable. A list of timestamps is not a history: "Version 2 · Saved · 14:03" beside "Version 3 · Saved · 14:05" tells a candidate nothing about which one to bring back, and the only way to find out used to be to restore one and look at it. Each row now carries the note the candidate wrote when they saved and a count of what is in that version, which is the difference people are actually looking for — the long one, before it was cut down. Restore replaces the working draft, so the row says so rather than leaving somebody to discover it. Undo takes it back; the draft keeps a snapshot ring and a restore is one more entry in it. {% endcomment %} {% url 'resume:builder_act' document_id=document.public_id as act %}
