{% now "Y" as current_year %} {% comment %} The site footer: a compact, secondary map of the public site. Rendered once, from `base.html`. Working screens (`layouts/app.html`) and the builder turn it off, and the sign-in screens have their own one-line footer. Why it used to run so long: * the grid was `grid-cols-[1.4fr_repeat(auto-fit,minmax(9rem,1fr))]`, which is not valid CSS — an auto-fit repeat cannot sit beside a flexible `fr` track — so the browser dropped the rule and every group stacked in one column, on a desktop as much as a phone; * below 640px the groups were one column with 2.5rem between them and every link on its own line, about 1,000px of footer on a phone; * two employer links led to one URL. Now: brand across the top on small screens with the groups two-up under it, four-up on a tablet, one row on a desktop. Links come from `core.navigation.FOOTER_NAV`, which drops anything behind a feature that is off. {% endcomment %}
